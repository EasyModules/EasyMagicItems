# Changelog

## 1.0.2

- Refined the card entrance to match the approved EasyTrials-style pacing with a softer fade, gentler movement, and synchronized per-card audio.
- Added a visible white-blue border glow and light sweep without clipping inside the card frame.
- Removed abandoned animation paths, duplicate entrance cleanup, unused template data, and obsolete configuration styles.
- Restored and verified every bundled audio file and third-party license document in the release package.
- Reviewed the manifest, public API version, documentation, local asset references, and GitHub release paths.

## 1.0.1

- Added a synchronized card-by-card opening sequence using shared absolute timestamps for every connected client.
- Cards now remain hidden until their individual entrance begins, then arrive, flip, and receive a luminous sweep with matching per-card audio.
- Shortened the opening theme and refined its fade-out.
- Added a separate client setting for the opening theme. The master audio setting continues to silence all music and effects.
- Locked draw interactions until the cinematic entrance has completed.
- Updated the manifest, dependency links, installation instructions, and support links for public GitHub distribution.
